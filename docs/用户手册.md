# 用户手册

## 1. 产品简介

`main-ui-kit` 是一个面向 Web 的场景化 UI/视口工具包，适合快速搭建编辑器、地图视图、关卡配置页、小游戏聚合主界面等应用。

核心能力：

1. 2D 节点视图渲染（Canvas）。
2. 地图式视口平移/缩放（Map）。
3. 本地保存、加载、JSON 导入导出。
4. 命令驱动操作（便于扩展撤销重做与工具栏动作）。

## 2. 快速开始

### 2.1 环境要求

1. Node.js 20+。
2. `pnpm`。

### 2.2 安装与启动

```bash
pnpm install
pnpm dev
```

默认启动 `apps/web-host` 演示页面。

## 3. 页面功能说明

当前默认页面包括以下区域：

1. 顶部信息区：显示模式、节点数量、相机状态、导出版本、状态消息。
2. 操作区（按钮）：
- `新增节点`
- `平移相机`
- `缩放相机`
- `保存到本地`
- `从本地加载`
- `导出 JSON`
- `导入 JSON`
3. 中部视口：
- `Canvas 图元视图`：显示节点图元与选中高亮。
- `Map 视口`：支持拖拽、滚轮缩放、相机状态同步。
4. 导出预览区：实时展示导出的 JSON 结构。

## 4. 常用操作

### 4.1 保存与加载

1. 点击 `保存到本地`，写入 `localStorage(scene-kit:last)`。
2. 点击 `从本地加载`，读取并覆盖当前场景。

### 4.2 导出与导入

1. 点击 `导出 JSON` 下载 `scene-export.json`。
2. 点击 `导入 JSON` 选择文件：
- 合法文件：更新场景。
- 非法文件：提示导入失败，页面不崩溃。

### 4.3 相机操作

1. 点击 `平移相机`：改变相机中心坐标。
2. 点击 `缩放相机`：改变相机 zoom。
3. 可在页面相机状态文本看到实时变化。

## 5. 面向“小游戏集锦主界面”的用法

如果你要做一个“左侧栏 + 右侧栏 + 顶部工具条 + 底部状态栏 + 中间 2D 视口”的主界面：

1. 左侧栏：显示游戏列表、分类、筛选。
2. 顶部工具条：放置导入导出、视口缩放、布局切换按钮。
3. 中间视口：使用 `mode-map`/`mode-canvas` 渲染游戏卡片或关卡入口节点。
4. 右侧栏：显示当前选中游戏详情（封面、说明、启动配置）。
5. 底部状态栏：显示相机坐标、缩放倍率、最近命令、导入导出状态。

## 6. 常见问题

1. 问：相机按钮点击后视口无变化？
答：确认使用了受控相机同步（`camera + onCameraChange`），并使用最新 `playwright` 回归版本。

2. 问：导入 JSON 报错？
答：检查字段是否满足协议要求（`scene/level/entities/metadata`）。

3. 问：能否只用本地存储不用导出？
答：可以，直接使用 `保存到本地/从本地加载`。
